Signal4KaiOS OStore source

This page is an app source for OStore (KaiOS 3.0+).

In OStore, choose Add source and enter this page's address:

https://ambercaravalho.github.io/signal4kaios/

Signal4KaiOS needs your own self-hosted backend (signal-cli-rest-api plus the gateway). Set it up before installing: Setup guide.
